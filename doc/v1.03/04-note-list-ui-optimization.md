# 笔记列表 UI 优化

## 变更概述

中间列表栏功能过多导致拥挤，优化布局：排序/视图/批量改为图标移到搜索栏同一行，导航按钮紧贴标题，摘要卡片美化。

## 变更文件

| 文件 | 变更内容 |
|------|----------|
| `src/renderer/components/note/NoteList.vue` | 布局重构：标题行（导航+标题+新建），工具栏（搜索+排序图标+视图图标+批量图标）；摘要卡片新增文档图标、间距优化 |

## 布局变化

```
之前:
  标题行: [导航按钮] [标题] [排序下拉(带文字)] [视图切换] [批量] [新建]
  搜索行: [搜索框]

现在:
  标题行: [导航按钮][标题]                                    [新建]
  工具栏: [搜索框____________] [排序图标] [视图图标] [批量图标]
```

## 优化细节

- 排序按钮：移除文字标签，只保留图标
- 视图切换：图标按钮，紧挨排序按钮
- 批量操作：改为图标按钮，不再显示文字
- 导航按钮：`gap: 0`，紧贴标题左侧
- 摘要卡片：每张卡片左侧新增 32x32 圆角文档图标（摘要模式）/ 24x24（列表模式）
- 卡片间距增大：padding `12px`，gap `10px`
