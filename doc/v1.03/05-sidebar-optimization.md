# 侧边栏布局优化

## 变更概述

侧边栏功能多、拖拽卡手，优化为：菜单项改为紧凑图标栏，移除拖拽分隔条，底部外部文件改为可折叠面板。

## 变更文件

| 文件 | 变更内容 |
|------|----------|
| `src/renderer/components/layout/AppSidebar.vue` | 移除拖拽调整逻辑；菜单改为图标栏；底部改为可折叠面板 |

## 布局变化

```
之前:
  顶部固定(35%可拖拽): 标题 + 搜索 + 菜单(文字列表)
  [拖拽分隔条]
  中间滚动: 分类 + 归档 + 标签
  [拖拽分隔条]
  底部固定(25%可拖拽): 外部文件

现在:
  顶部固定: 标题 + 搜索 + 图标菜单(单行不换行)
  中间滚动: 分类 + 归档 + 标签
  底部可折叠: 外部文件(点击展开/收起, max-height 40%)
```

## 优化细节

- 7 个菜单项从文字列表改为 32x32 图标网格，单行排列不换行
- 移除两个拖拽分隔条及 `menuHeight`/`bottomHeight` 状态
- 底部外部文件区域改为点击折叠/展开，不再需要拖拽调整
- 移除 `saveLayout`/`loadLayout` 的 localStorage 持久化
