# 启动页白厄风格配色

## 变更概述

启动过渡页采用白厄风格黄紫配色，深紫底色 + 鎏金光效。

## 变更文件

| 文件 | 变更内容 |
|------|----------|
| `src/renderer/index.html` | splash 配色改为白厄风格黄紫主题 |

## 配色方案

| 元素 | 配色 |
|------|------|
| 背景 | 深紫渐变 `#0d0a1a → #1a1035 → #2a1548 → #1f0f3a` |
| 背景光晕 | 金色 `rgba(245,200,66,0.08)` + 紫色 `rgba(120,50,180,0.1)` |
| Logo | 鎏金渐变 `#f5c842 → #e8a020 → #c4881a → #8b5e14` |
| 标题 | 金色流光 `#f5c842 → #ffd866 → #f0b030`，shimmer 动画 |
| Spinner | 紫底 `rgba(120,50,180,0.2)` + 金顶 `#f5c842` |
| 副标题/文字 | 淡紫半透明 `rgba(180,160,210,0.4~0.6)` |

## 动画

- `logoPulse`：Logo 呼吸缩放 + 光晕变化，3s 循环
- `bgShift`：背景光晕缓慢漂移，10s 循环
- `titleShimmer`：标题流光效果，4s 循环
- `spin`：Spinner 旋转，0.7s 循环
